# S-04: Seed データ & 共通ユーティリティ

# 要件概要

## 目的
- JST 日付ユーティリティを実装し、SRS ロジック（E-02）の基盤を整える
- 小学3年生配当漢字の Seed データ（R1/W1 カード）を作成し、開発・テスト時にすぐ学習フローを動かせる状態にする
- デフォルトデッキを作成し、Seed カードを紐付ける

## 解決する課題
- JST 基準の日付計算が全エピックで必要（due_date の計算、「今日」「明日」の判定）
- E-02 の学習フロー開発時にカードデータが無いと動作確認できない
- 小3配当漢字データの正確な投入

# 機能要件の詳細

## 1. JST 日付ユーティリティ

### 関数一覧（`src/lib/date.ts`）

#### `getTodayJST(): string`
- 現在の JST 日付を `YYYY-MM-DD` 形式で返す
- 例: UTC 2026-02-23T15:00:00Z → JST 2026-02-24 → `"2026-02-24"`

#### `getTomorrowJST(): string`
- JST の翌日を `YYYY-MM-DD` 形式で返す

#### `addDaysJST(baseDate: string, days: number): string`
- JST 基準日に指定日数を加算した日付を返す
- `baseDate`: `YYYY-MM-DD` 形式
- 例: `addDaysJST("2026-02-23", 3)` → `"2026-02-26"`

#### `isBeforeOrEqualJST(date: string, target: string): boolean`
- `date <= target` を判定（`YYYY-MM-DD` 文字列の比較）
- due_date が今日以前かどうかの判定に使用

### 設計方針
- `Intl.DateTimeFormat` または `Date` オブジェクトの `toLocaleDateString` で JST 変換
- 外部ライブラリ（dayjs等）は使用しない（シンプルな日付計算のみのため）
- テスト容易性のため、「現在日時」を注入可能な設計（テスト時にモック可能）

## 2. Seed データ（小学3年生配当漢字）

### 対象漢字
小学3年生の配当漢字（200字）から、MVP 用に代表的な漢字を選定して Seed データを作成する。

### カード作成ルール
各漢字につき、以下の2枚のカードを作成:

**R1（読みカード）**:
- `skill`: `'reading'`
- `pattern`: `'R1'`
- `front_text`: 漢字を含む単語（例: `"温かい"`）
- `back_text`: ひらがな読み（例: `"あたたかい"`）
- `card_key`: `"R1:{front_text}:{back_text}"` のハッシュまたは結合文字列

**W1（書きカード）**:
- `skill`: `'writing'`
- `pattern`: `'W1'`
- `front_text`: ひらがな読み（例: `"あたたかい"`）
- `back_text`: 漢字を含む単語（例: `"温かい"`）
- `card_key`: `"W1:{front_text}:{back_text}"` のハッシュまたは結合文字列

### 全カードの属性
- `visibility`: `'public'`
- `owner_user_id`: `NULL`（公開カード）
- `illustration_key`: 漢字の代表語をキーとして設定（例: `"温かい"`）

### Seed データの件数目安
- MVP では小3配当漢字から **50〜100字** を選定（開発・テストに十分な量）
- 各漢字 × 2枚（R1 + W1） = 100〜200枚のカード

## 3. デフォルトデッキ

### デッキ定義
- `name`: `"小学3年生の漢字"`
- `new_limit_per_day`: `10`

### カード紐付け
- `deck_cards` テーブルに、デフォルトデッキと全 Seed カードの紐付けを INSERT

### デッキの所有者
- Seed スクリプト実行時に指定するユーザーID を `owner_user_id` として設定
- または、Supabase の Service Role Key を使用して RLS をバイパスし、特定ユーザーにデッキを作成

## 4. Seed スクリプト

### 実装方法
- `supabase/seed.sql` として SQL ファイルを作成
- または `scripts/seed.ts` として TypeScript スクリプトを作成（Service Role Key 使用）

### 実行方法
- `supabase db reset` 時に自動実行（`supabase/seed.sql` の場合）
- または `npx tsx scripts/seed.ts` で手動実行

### 冪等性
- カードの `card_key` が UNIQUE 制約を持つため、重複 INSERT はエラーになる
- `ON CONFLICT (card_key) DO NOTHING` で冪等性を確保

# 技術要件

## JST 日付ユーティリティのテスト

### テストケース（`src/lib/date.test.ts`）

| テスト | 入力 | 期待出力 |
|--------|------|---------|
| JST 深夜0時（UTC 15:00前日） | UTC: 2026-02-23T15:00:00Z | `"2026-02-24"` |
| JST 23:59（UTC 14:59同日） | UTC: 2026-02-24T14:59:00Z | `"2026-02-24"` |
| 日数加算 | `addDaysJST("2026-02-28", 1)` | `"2026-03-01"` |
| 月跨ぎ | `addDaysJST("2026-12-31", 1)` | `"2027-01-01"` |
| 日付比較 | `isBeforeOrEqualJST("2026-02-23", "2026-02-23")` | `true` |
| 日付比較 | `isBeforeOrEqualJST("2026-02-24", "2026-02-23")` | `false` |

## card_key の生成ルール
- 形式: `"{pattern}:{front_text}:{back_text}"` をそのまま使用（ハッシュ不要、十分にユニーク）
- 例: `"R1:温かい:あたたかい"`, `"W1:あたたかい:温かい"`

## 漢字データの正確性
- 小学3年生配当漢字は文部科学省の学習指導要領に基づく
- 読みは常用漢字表の読みに準拠
- 代表的な単語（教科書で使われる一般的な用例）を選定
